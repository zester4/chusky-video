Editable HyperFrames composition, separately composed for a 1080×1920 portrait canvas at 30 fps and 60 seconds. The ten scenes use the approved launch storyboard, re-laid out for portrait reading order; they are not scaled or cropped landscape scenes.

- Composition: `index.html`
- Scene-by-scene outline and voiceover: `storyboard.md`
- Local brand assets: `assets/` (official Chusky wordmark and the project's existing Instrument / JetBrains fonts)
- Audio: none included. No audio file was supplied or generated. Use the narration in `storyboard.md` as the recording script. No voice or music is claimed as recorded or licensed.
- Parent project/storyboard: `../../STORYBOARD.md` and `../../SCRIPT.md`

All staged screens are illustrative and use generic Prospect 01–03 / Company A–C labels. The cut does not represent customer-result evidence. The approval gate remains visible before outbound work; the later check-in is conditional and does not imply conversion.

This project has not been run through the HyperFrames CLI or rendered. The composition is provided as editable source for the main project's documented preview, validation, and render workflow.
